# pokeapi-pipeline

Extracts Pokémon data from [PokeAPI](https://pokeapi.co/) with Python, to be loaded into Snowflake and transformed there with SQL.

Built for my Tableau dashboard, [The People's Pokémon](https://public.tableau.com/app/profile/kristupas.jucaitis/viz/ThePeoplesPokmon/Home).

## Setup

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
